# NAIce Shot 화면 규칙

UI를 고치기 전에 이 문서를 읽는다. GPT와 Claude가 번갈아 고쳐도 모양이 어긋나지 않게 하려는 공통 기준이다. 규칙을 바꿀 때는 이 문서와 검사를 함께 고친다.

## 1. 강조 세 단계

| 단계 | 쓰는 곳 | 모양 |
| --- | --- | --- |
| **주 버튼** `.ncs-primary` | 그 영역에서 가장 중요한 한 가지: 이미지 생성, 장면 추출, 글로 채우기, 새 프리셋으로 저장, 프로필 저장 | 테마의 주 색으로 채움 |
| **테두리 강조** `.ncs-accent`, `.ncs-save-toggle`, 저장 메뉴의 첫 항목 | 자주 쓰지만 주 버튼은 아닌 것: 저장 ▾, 보기 범위, 공유용 PNG | 테마 `--ncs-edge` 색 테두리 + 옅은 같은 색 배경 |
| **기본** | 나머지 | 테마 기본 버튼 |

- 영역(`.ncs-actions` 하나)마다 **주 버튼은 하나**만 둔다.
- 지우기·삭제는 `.ncs-danger-outline`(빨간 테두리). 되돌릴 수 없는 동작을 주 버튼으로 만들지 않는다(예: 덮어쓰기는 주 버튼이 아니다).

## 2. 버튼 묶음 `.ncs-actions`

- 주 버튼은 `.ncs-action-main`으로 **한 줄 전체**.
- 보조 버튼은 **같은 폭 두 칸**.
- 삭제는 `.ncs-action-remove`로 마지막 줄 오른쪽에 작게 떼어 둔다.
- 비우기처럼 보조 동작 하나는 `.ncs-action-slot`(오른쪽 아래 작게). 비운 직후 같은 자리가 "↶ 비우기 취소"로 바뀐다.
- 묶음 폭은 **최대 560px**. 넓은 PC 화면에서 버튼이 늘어나지 않는다.
- 버튼 글자는 **한 줄**. 길면 줄인다("카드 연결", "덮어쓰기 · 이름"). 아주 좁은 폰(360px 이하)에서는 한 칸에 하나씩 쌓거나 짧은 글자(`.ncs-wide-only` 숨김)를 쓴다.

## 3. 고정된 배치

- 이력 도구: **[표시된 항목 모두 선택] [선택 저장 ▾] [선택 삭제] / [이 채팅 이력 전체 삭제]**. 바꾸려면 사용자와 먼저 정한다.
- 이력 카드: 날짜 → **[저장 ▾] [삭제] [⋯]**. ⋯ 메뉴 순서: 챗샷으로 보내기 · 본문에 넣기 · 설정을 프리셋으로 · 프리샷으로 보내기.
- 새로고침은 개수 옆 작은 ↻(`.ncs-icon-button`).
- 인물 카드의 옷: **이번 그림**(복장 칸 · 옷장에서 꺼내 입기 · 기본 복장 입기 · 비우기 · 직접 고쳤을 때만 자동으로 되돌리기) / **이 채팅에서**(채팅 기본 복장 · 지금 옷을 기본으로 · 옷장에 저장 · 복장 잠금 · 해제 취소는 이 안에).
- 저장하는 동안에는 그 카드의 버튼만 잠근다. 그리기창 전체를 회색으로 만들지 않는다.

## 4. 메뉴

- 저장 메뉴는 두 항목(공유용 PNG / 원본 PNG)과 한 줄 설명만. 긴 안내는 설정의 "PNG 저장 안내"와 설명서에 둔다.
- 메뉴 배경은 항상 불투명(`--ncs-menu-bg`). 반투명 테마도 메뉴 뒤 글자가 비치지 않는다.
- 아래 공간이 부족하면 버튼 위로 연다. 저장 메뉴는 버튼 왼쪽 끝, ⋯ 메뉴는 오른쪽 끝에 맞춘다.

## 5. 테마

- 테마 파일(`skins/*.css`)은 **색·모서리·그림자·장식만** 바꾼다. 크기·간격·배치(display, width, margin, padding, grid, flex, position …)는 `style.css`에서만 정한다. `tests/skins-lint.test.mjs`가 막는다.
- 글자 대비 4.5:1 이상(큰 글자 3:1). 마우스를 올린 상태도 포함한다.

## 6. 검사

| 검사 | 확인하는 것 |
| --- | --- |
| `tests/skins-lint.test.mjs` | 테마 파일에 배치 속성이 없는지 |
| `tests/browser-v0149.mjs` | 17개 테마 글자 대비(메뉴 연 상태 포함), 메뉴 불투명, 320/375/1100px 가로 넘침 없음, 주요 버튼 한 줄, 묶음마다 주 버튼 하나, 이력 도구 배치, 작은 ↻, PC 묶음 폭, 비우기 ⇄ 비우기 취소 |

UI를 바꾸면 이 두 검사를 꼭 돌린다. 의도적으로 규칙을 바꿨다면 문서·검사·리뷰 기록을 같이 고친다. 리뷰 기록에는 "이번에 건드린 화면"을 한 줄 적는다.
