# NAIce Shot 화면 규칙

UI를 고치기 전에 이 문서를 읽는다. GPT와 Claude가 번갈아 고쳐도 모양이 어긋나지 않게 하려는 공통 기준이다. 규칙을 바꿀 때는 이 문서와 검사를 함께 고친다.

## 1. 강조 세 단계

| 단계 | 쓰는 곳 | 모양 |
| --- | --- | --- |
| **주 버튼** `.ncs-primary` | 그 영역에서 가장 중요한 한 가지: 이미지 생성, 장면 추출(챗샷·프리샷 공통), 새 프리셋으로 저장, 프로필 저장 | 테마의 주 색으로 채움 |
| **테두리 강조** `.ncs-accent`, `.ncs-save-toggle`, 저장 메뉴의 첫 항목 | 자주 쓰지만 주 버튼은 아닌 것: 저장 ▾, 보기 범위, 클린 PNG | 테마 `--ncs-edge` 색 테두리 + 옅은 같은 색 배경 |
| **기본** | 나머지 | 테마 기본 버튼 |

- 영역(`.ncs-actions` 하나)마다 **주 버튼은 하나**만 둔다.
- 지우기·삭제는 `.ncs-danger-outline`(빨간 테두리). 되돌릴 수 없는 동작을 주 버튼으로 만들지 않는다. 예외: 고른 프리셋의 **[변경 저장 · 이름]**은 확인 창과 함께 주 버튼이다(고르지 않았으면 [새 프리셋으로 저장]만).

## 2. 버튼 묶음 `.ncs-actions`

- 주 버튼은 `.ncs-action-main`으로 **한 줄 전체**.
- 보조 버튼은 **같은 폭 두 칸**.
- 삭제는 `.ncs-action-remove`로 마지막 줄 오른쪽에 작게 떼어 둔다.
- 비우기처럼 보조 동작 하나는 `.ncs-action-slot`(작게). 비운 직후 같은 자리가 "↶ 비우기 취소"로 바뀐다. 그리기창 비우기는 **"2 · 장면 편집" 제목 오른쪽** `.ncs-clear-slot` 한 곳(두 모드 공통, 되돌리기는 모드마다 따로).
- PC에서는 내용이 **패널 전체 폭**을 쓰고(0.1.58, 640px 열 해제), 버튼 묶음도 입력칸과 같은 폭이라 끝이 같다.
- 버튼 글자는 **한 줄**. 길면 줄인다("카드 연결", "덮어쓰기 · 이름"). 사용자가 정한 이름이 들어가는 버튼은 "…"로 자르고 전체 이름은 title에 둔다. 아주 좁은 폰(360px 이하)에서는 한 칸에 하나씩 쌓거나 짧은 글자(`.ncs-wide-only` 숨김)를 쓴다.

## 3. 고정된 배치

- 이력 도구: **[표시된 항목 모두 선택] [선택 저장 ▾] [선택 삭제] / [이 채팅 이력 전체 삭제]**, 그 아래 접지 않은 **PNG 저장 안내**(개인정보 주의와 같은 강조). 바꾸려면 사용자와 먼저 정한다.
- 이력 카드: 맨 윗줄 **선택 체크 | ☆/★**(0.1.86: 별은 카드 오른쪽 위, 체크박스 크기의 작은 동그라미) → 그림 → **날짜** → (있으면) 태그 칩 `#웃음` → **[⋯] [저장 ▾] [삭제]**(0.1.73: 확대창 아랫줄 1과 같은 배치, ⋯ 메뉴는 ⋯ 왼쪽 끝에서 열림). ⋯ 메뉴 순서: 챗샷으로 보내기 · 프리샷으로 보내기 · 설정을 프리셋으로 · 본문에 넣기 · (붙어 있으면) 채팅에서 이 그림 빼기 · **태그 편집**(0.1.84, 프리샷 그림은 흐리게 이유) · 구분선 · 메시지로 가기(만든·넣은 메시지가 같으면 한 줄, 다르면 두 줄). 태그 편집 칸은 프리셋 이름 칸처럼 카드 아래에 열린다(Enter로 저장).
- 개수 줄: 개수 · **[☆ 즐겨찾기만]**(`.ncs-star-filter`) · **[# 태그]**(0.1.86) · [↻ 새로고침](`.ncs-refresh-button`)(모두 작은 버튼). ★를 켜면 ★ 그림만 "즐겨찾기 N장", #를 켜면 태그 붙은 그림만 "태그 N장". **★와 #는 둘 중 하나만** 켜진다. #를 켜면 목록 위에 접힌 설명("답변에 태그 단어가 나오면 팝업으로 떠요. 더보기 ›", 모든 폭에서 접힘). 이력 전체 삭제의 장수는 거르지 않은 수.
- 0.1.89(사용자 결정): 개수 줄은 **개수가 한 줄을 다 쓰고, ☆ · # · ↻ 새로고침은 그 아래 줄 오른쪽**. 모든 폭에서 늘 두 줄(긴 개수 "저장 대기 N장 · N MB"도 버튼을 밀지 않음). `browser-v0189`.
- 새로고침은 개수 아래 작은 "↻ 새로고침" 버튼(`.ncs-refresh-button`). 폰에서는 마우스를 올리는 설명이 안 보이므로 글자를 함께 쓴다.
- 이력 탭의 긴 설명(보기 설명, 저장 위치)은 접고, PNG 저장 안내 같은 경고는 펴 둔다.
- 인물 카드의 옷: **이번 그림**(이번 그림 복장 칸 · 옷장에서 꺼내 입기 · [기본 복장 입기][비우기] · 직접 고쳤을 때만 자동으로 되돌리기 · **"이 복장을"** 줄 [이 채팅 기본으로][옷장에 저장]) / **이 채팅에서**(채팅 기본 복장 · 복장 잠금 · 접힌 "ⓘ 잠금이 뭐예요?" · 해제 취소는 이 안에).
- 고정 외형·전용 태그는 카드에서 펼쳐 **바로 고친다. 고친 내용은 이번 그림에만** 쓰이고 프로필은 그대로다(0.1.70, 챗샷·프리샷 공통). 고쳤으면 "이번 그림만 고침" 표시와 [프로필 값으로 되돌리기]. 프로필 자체는 작은 **[프로필 편집]**이 프로필 탭과 같은 편집기를 그리기 탭 안에 연다(저장 전 "모든 채팅에 적용" 확인, 작성 중인 내용은 다른 프로필을 열기 전에 묻는다).
- 옷장에 저장할 이름 칸은 **[옷장에 저장] 바로 아래**에 연다(0.1.70).
- 새 프로필은 늘 **직접 입력**에서 시작한다. 설명으로 만들기는 눌러서 바꾸고, 기억하지 않는다(0.1.70).
- 저장하는 동안에는 그 카드의 버튼만 잠근다. 그리기창 전체를 회색으로 만들지 않는다.


## 3-1. 그리기 탭 (0.1.55)

- **챗샷·프리샷은 한 화면을 나눠 쓴다.** 공통: 추출 표현, 장면 편집·인물 카드·생성 설정·최종 프롬프트·결과, [장면 추출], 그리기창 비우기. 챗샷 전용: 대상 메시지, 보낼 메시지 수, 유저 메시지 포함, 채팅 프로필 연결, 장면 후보, 추가 요청, 채팅 기본 복장·잠금. 프리샷 전용: 상황 입력. 한쪽만 고치지 않는다. 공통 기능 검사는 두 모드에서 돈다(`browser-v0155`).
- 실행 버튼은 하나(**[장면 추출]**), 모드에 따라 챗샷은 메시지, 프리샷은 적은 상황을 보낸다.
- 챗샷/프리샷 전환은 **제목 줄, 제목 바로 옆**(0.1.67, 사용자 선택 A). 높이는 제목+부제목과 같고 부제목을 가리지 않는다. **모든 탭에서 보이고**, 다른 탭에서 눌러도 그 탭에 머문다(0.1.68). 작업 칸이 잠기면 같이 잠긴다. 따라오는 막대는 두지 않는다. 360px 이하에서만 부제목을 숨긴다.
- 프리샷 인물 카드: 위쪽 **[📌 고정][제거]**. 추출하면 글에 이름이 없는 카드는 지워지고(고정이면 남기고 체크 해제), 지우거나 체크가 풀릴 카드가 있으면 먼저 묻는다. 체크는 성공한 추출마다 글대로 다시 정해진다. 프리샷에는 복장 잠금이 없다(직접 고른 옷이 남는다).
- [↶ 추출 취소]는 [↶ 가져오기 취소]와 같은 자리(비우기 옆 작은 버튼). 그리기 작업 취소는 한 칸: 비우기·가져오기·추출 중 가장 최근 하나.
- **[↓ 생성]**: 그리기 탭에서 "3 · 생성" 영역이 화면 밖일 때 오른쪽 아래에 뜨는 작은 버튼. 누르면 실제 생성 영역(경고·Anlas 확인 포함)으로 이동한다. 생성 버튼을 복제하지 않는다.
- **추가 요청**은 후보가 없을 때 [장면 추출] 위, 후보가 생기면 후보 바로 아래 상자(+ [이 요청으로 다시 추출]). 반영한 것·반영하지 않은 것을 한 줄로 보여준다.
- [인물 추가]는 테두리 강조, 프로필 없는 칸은 [+ 인물 칸 추가].

## 4. 메뉴

- 저장 메뉴는 두 항목(클린 PNG / 원본 PNG)과 한 줄 설명만. 긴 안내는 이력 탭의 "PNG 저장 안내"와 설명서에 둔다.
- 문구: 클린 PNG "프롬프트·seed 등 메타데이터를 제거한 사본이에요." / 원본 PNG "프롬프트·seed 등 메타데이터를 제거하지 않고 그대로 저장해요." EXIF는 안내에서 "메타데이터의 한 종류"로만 설명한다(프롬프트가 꼭 EXIF로 들어가는 건 아님).
- 메뉴 항목에 포커스가 가도 테두리는 한 겹이다(포커스 테두리는 항목 안쪽).
- 메뉴 배경은 항상 불투명(`--ncs-menu-bg`). 반투명 테마도 메뉴 뒤 글자가 비치지 않는다.
- 아래 공간이 부족하면 버튼 위로 연다. 저장 메뉴는 버튼 왼쪽 끝, ⋯ 메뉴는 오른쪽 끝에 맞춘다.

## 4-1. 크기와 여백 (0.1.86, 사용자 확정: 여백 "중간" + 36px)

- 크기·여백은 `style.css` 맨 아래 "0.1.86" 묶음에서 정한다(테마 파일 금지).
- PC / 폰(520px 이하): 헤더 `12px 16px` / `9px 11px`, 탭 줄 `7px 13px` / `5px 7px`, 알림 `7px 16px` / `7px 11px`, 본문 `0 16px 13px` / `0 11px 11px`, 푸터 `9px 16px` / `7px 11px`.
- 구역 위아래 12px, h3 아래 7px, 설명 문단 `5px 0 9px`·줄간 1.52, label 위아래 7px, `.ncs-row` 9px, 인물 카드 안쪽 11px(폰 8px)·바깥 9px, summary 6px, details 위 8px.
- 버튼·입력칸·선택칸·칩칸·숫자 −/+·대상 메시지 요약·옷장 줄·이력 카드 버튼은 **높이 36px**(안쪽 위아래 7px). 챗샷/프리샷 같은 두 칸 전환은 32px. 주 버튼 한 줄(`.ncs-action-main`)은 그대로 50px. → 0.1.88 크기 기준으로 바뀜(아래).
- 마우스를 올린 색(`:hover`)은 **`@media (hover:hover)` 안에만** 쓴다. 폰에서 누른 뒤 색이 남지 않게(테마 파일 포함). `browser-v0186`이 막는다.

### 0.1.88 크기 기준 (사용자 확정: 실제 패널 시안에서 "A 38 + 설명 12")

- 버튼은 세 가지: **주 버튼 38px**(장면 추출·이미지 생성·프로필 저장·새 프리셋 저장, 글자 15 굵게) / **보통 36px**(그 밖의 버튼·입력칸·선택칸, 글자 14) / **작은 버튼 32px**(☆ · # · ↻ 새로고침 · 비우기 · 작업 바 버튼 · 계정 ↻, 글자 13). 탭은 36px·글자 14(320px처럼 아주 좁으면 아이콘 위·글자 아래 그대로).
- 글자는 제목(h3) 16 / 본문 14 / 설명 12 / 날짜·개수·접힌 줄 값 12. 이력 카드 [저장][삭제] 글자 13.
- `style.css` 맨 아래 "0.1.88" 묶음에서 정한다. `browser-v0188`이 320·375·1100px에서 높이·글자를 본다.
- 이력 선택 도구는 한 줄 [모두 선택↔모두 해제] [본문에 넣기] [저장▾] [삭제](프리샷은 본문에 넣기 없이 셋), 아래 줄 전체 삭제. 버튼에 장수를 붙이지 않고 개수 줄에 "N장 고름". ☆·#는 아이콘만(이름은 aria-label·title).
- 패널을 열면 패널 자체가 첫 포커스(버튼에 포커스 링이 생겨 커 보이지 않게). 두 칸 전환의 포커스 링은 안쪽에.
- Anlas 허용이 꺼져 있다는 안내 옆에는 **같은 설정의 체크칸**(위 체크칸과 함께 켜지고 꺼짐). 버튼 하나로 저절로 켜지지 않는다(0.1.46)는 그대로: 사용자가 체크한다.
- 사용 가이드(0.1.89 이후): 이름 아래 부제목 자리에 "📖 사용 가이드 ›". 내용이 생기기 전에는 넣지 않는다.

## 4-2. 설명 접기 (0.1.86, 폰만)

- 폰(520px 이하)에서는 긴 설명을 **한 줄 요약 + "더보기 ›"**, 펼치면 원래 문장 전체 + "접기 ‹". PC는 늘 전체 문장. 이어지는 두 줄 이상의 한 설명은 더보기 하나로 묶는다.
- 표시: `<div class="ncs-help" data-short="한 줄 요약">원래 문장들</div>`(index.js `setupHelpFolds`가 요약 줄과 버튼을 붙인다). 0.1.87: 한 칸 아래 이어지는 설명은 **더보기 하나**로 합친다(요약은 두 문장까지). 이력 # 태그 설명은 없어지고 설정 "태그 추천 팝업" 설명에 합쳤다(`.ncs-help-always` 없음).
- **접지 않는다:** 비용(Anlas·V5·무료 크기·추출 AI 비용), 개인정보(응답 원문·백업·계정 정보), 삭제·되돌릴 수 없음, 저장되는 데이터(생성 기록·PNG·파일명·저장 위치, 0.1.87: "장면·프롬프트는 서버에 따로 기억해요"·"고친 내용은 채팅별 마지막 작업에 함께 기억해요"는 접는 설명 밖 한 줄), 서버 상태, 추출 결과 확인 안내, 공식 프리셋 안내, "하이드한 메시지도 고를 수 있어요." `browser-v0186`·`browser-v0187`이 접힌 설명에 이런 말(기억해요 포함)이 없는지 본다.
- 계정 응답 항목 목록(설정)은 "문제가 생겼을 때" 한 칸으로 접고, 열면 개인정보 안내(`.ncs-privacy-note`)가 먼저 보인다.
- 공통 프롬프트 Negative 칸 바로 아래 연한 한 줄(늘 보임): "공식 사이트의 퀄리티 태그·부정 프리셋은 자동으로 붙지 않아요. 쓰던 분은 직접 넣어 주세요."

## 5. 테마

- 테마 파일(`skins/*.css`)은 **색·모서리·그림자·장식만** 바꾼다. 크기·간격·배치(display, width, margin, padding, grid, flex, position …)는 `style.css`에서만 정한다. `tests/skins-lint.test.mjs`가 막는다.
- 글자 대비 4.5:1 이상(큰 글자 3:1). 마우스를 올린 상태와 투명도(opacity)를 합성한 색으로 계산한다. 흐린 글씨는 opacity 대신 `--ncs-muted` 색을 쓴다.
- 고른 상태(`--ncs-tab-active-bg`)를 배경으로 쓰면 글자는 **`--ncs-tab-active-fg`**(0.1.86: 대상 메시지 목록·@ 목록의 고른 줄, ✓ 포함). 애플처럼 진한 색 위에서도 읽혀야 한다.
