# NAIce Shot 화면 규칙

UI를 고치기 전에 이 문서를 읽는다. GPT와 Claude가 번갈아 고쳐도 모양이 어긋나지 않게 하려는 공통 기준이다. 규칙을 바꿀 때는 이 문서와 검사를 함께 고친다.

## 1. 강조 세 단계

| 단계 | 쓰는 곳 | 모양 |
| --- | --- | --- |
| **주 버튼** `.ncs-primary` | 그 영역에서 가장 중요한 한 가지: 이미지 생성, 장면 추출(챗샷·프리샷 공통), 새 프리셋으로 저장, 프로필 저장 | 테마의 주 색으로 채움 |
| **테두리 강조** `.ncs-accent`, `.ncs-save-toggle`, 저장 메뉴의 첫 항목 | 자주 쓰지만 주 버튼은 아닌 것: 저장 ▾, 보기 범위, 클린 PNG | 테마 `--ncs-edge` 색 테두리 + 옅은 같은 색 배경 |
| **기본** | 나머지 | 테마 기본 버튼 |

- 영역(`.ncs-actions` 하나)마다 **주 버튼은 하나**만 둔다.
- 지우기·삭제는 `.ncs-danger-outline`(빨간 테두리). 되돌릴 수 없는 동작을 주 버튼으로 만들지 않는다. 예외: 고른 프리셋의 **[변경 저장 · 이름]**은 확인 창과 함께 주 버튼이다(고르지 않았으면 [새 프리셋으로 저장]만).

## 2. 버튼 묶음 `.ncs-actions`

- 주 버튼은 `.ncs-action-main`으로 **한 줄 전체**.
- 보조 버튼은 **같은 폭 두 칸**.
- 삭제는 `.ncs-action-remove`로 마지막 줄 오른쪽에 작게 떼어 둔다.
- 비우기처럼 보조 동작 하나는 `.ncs-action-slot`(작게). 비운 직후 같은 자리가 "↶ 비우기 취소"로 바뀐다. 그리기창 비우기는 **"2 · 장면 편집" 제목 오른쪽** `.ncs-clear-slot` 한 곳(두 모드 공통, 되돌리기는 모드마다 따로).
- PC에서는 내용이 **패널 전체 폭**을 쓰고(0.1.58, 640px 열 해제), 버튼 묶음도 입력칸과 같은 폭이라 끝이 같다.
- 버튼 글자는 **한 줄**. 길면 줄인다("카드 연결", "덮어쓰기 · 이름"). 사용자가 정한 이름이 들어가는 버튼은 "…"로 자르고 전체 이름은 title에 둔다. 아주 좁은 폰(360px 이하)에서는 한 칸에 하나씩 쌓거나 짧은 글자(`.ncs-wide-only` 숨김)를 쓴다.

## 3. 고정된 배치

- 이력 도구: **[표시된 항목 모두 선택] [선택 저장 ▾] [선택 삭제] / [이 채팅 이력 전체 삭제]**, 그 아래 접지 않은 **PNG 저장 안내**(개인정보 주의와 같은 강조). 바꾸려면 사용자와 먼저 정한다.
- 이력 카드: 날짜 → **[저장 ▾] [삭제] [⋯]**. ⋯ 메뉴 순서: 챗샷으로 보내기 · 프리샷으로 보내기 · 설정을 프리셋으로 · 본문에 넣기 · 구분선 · 메시지로 가기(만든·넣은 메시지가 같으면 한 줄, 다르면 두 줄).
- 새로고침은 개수 옆 작은 "↻ 새로고침" 버튼(`.ncs-refresh-button`). 폰에서는 마우스를 올리는 설명이 안 보이므로 글자를 함께 쓴다.
- 이력 탭의 긴 설명(보기 설명, 저장 위치)은 접고, PNG 저장 안내 같은 경고는 펴 둔다.
- 인물 카드의 옷: **이번 그림**(이번 그림 복장 칸 · 옷장에서 꺼내 입기 · [기본 복장 입기][비우기] · 직접 고쳤을 때만 자동으로 되돌리기 · **"이 복장을"** 줄 [이 채팅 기본으로][옷장에 저장]) / **이 채팅에서**(채팅 기본 복장 · 복장 잠금 · 접힌 "ⓘ 잠금이 뭐예요?" · 해제 취소는 이 안에).
- 고정 외형·전용 태그는 펼쳐서 고치고 작은 [프로필 업데이트](확인 창, 한 번 [↶ 업데이트 취소]).
- 저장하는 동안에는 그 카드의 버튼만 잠근다. 그리기창 전체를 회색으로 만들지 않는다.


## 3-1. 그리기 탭 (0.1.55)

- **챗샷·프리샷은 한 화면을 나눠 쓴다.** 공통: 추출 표현, 장면 편집·인물 카드·생성 설정·최종 프롬프트·결과, [장면 추출], 그리기창 비우기. 챗샷 전용: 대상 메시지, 보낼 메시지 수, 유저 메시지 포함, 채팅 프로필 연결, 장면 후보, 추가 요청, 채팅 기본 복장·잠금. 프리샷 전용: 상황 입력. 한쪽만 고치지 않는다. 공통 기능 검사는 두 모드에서 돈다(`browser-v0155`).
- 실행 버튼은 하나(**[장면 추출]**), 모드에 따라 챗샷은 메시지, 프리샷은 적은 상황을 보낸다.
- 챗샷/프리샷 전환은 그리기 탭 맨 위에 고정(스크롤해도 보임).
- **추가 요청**은 후보가 없을 때 [장면 추출] 위, 후보가 생기면 후보 바로 아래 상자(+ [이 요청으로 다시 추출]). 반영한 것·반영하지 않은 것을 한 줄로 보여준다.
- [인물 추가]는 테두리 강조, 프로필 없는 칸은 [+ 인물 칸 추가].

## 4. 메뉴

- 저장 메뉴는 두 항목(클린 PNG / 원본 PNG)과 한 줄 설명만. 긴 안내는 이력 탭의 "PNG 저장 안내"와 설명서에 둔다.
- 문구: 클린 PNG "프롬프트·seed 등 메타데이터를 제거한 사본이에요." / 원본 PNG "프롬프트·seed 등 메타데이터를 제거하지 않고 그대로 저장해요." EXIF는 안내에서 "메타데이터의 한 종류"로만 설명한다(프롬프트가 꼭 EXIF로 들어가는 건 아님).
- 메뉴 항목에 포커스가 가도 테두리는 한 겹이다(포커스 테두리는 항목 안쪽).
- 메뉴 배경은 항상 불투명(`--ncs-menu-bg`). 반투명 테마도 메뉴 뒤 글자가 비치지 않는다.
- 아래 공간이 부족하면 버튼 위로 연다. 저장 메뉴는 버튼 왼쪽 끝, ⋯ 메뉴는 오른쪽 끝에 맞춘다.

## 5. 테마

- 테마 파일(`skins/*.css`)은 **색·모서리·그림자·장식만** 바꾼다. 크기·간격·배치(display, width, margin, padding, grid, flex, position …)는 `style.css`에서만 정한다. `tests/skins-lint.test.mjs`가 막는다.
- 글자 대비 4.5:1 이상(큰 글자 3:1). 마우스를 올린 상태와 투명도(opacity)를 합성한 색으로 계산한다. 흐린 글씨는 opacity 대신 `--ncs-muted` 색을 쓴다.

## 6. 검사

| 검사 | 확인하는 것 |
| --- | --- |
| `tests/skins-lint.test.mjs` | 테마 파일에 배치 속성이 없는지(대소문자 구분 없이) |
| `tests/browser-v0149.mjs` | 17개 테마 글자 대비(메뉴 연 상태·hover·투명도 포함), 메뉴 불투명, 320/375/1100px 가로 넘침 없음, 주요 버튼 한 줄, 묶음마다 주 버튼 하나, 이력 도구 배치, 작은 ↻, PC 묶음 폭, 비우기 ⇄ 비우기 취소 |

UI를 바꾸면 이 두 검사를 꼭 돌린다. 의도적으로 규칙을 바꿨다면 문서·검사·리뷰 기록을 같이 고친다. 리뷰 기록에는 "이번에 건드린 화면"을 한 줄 적는다.
