# NAIce Shot — 서버 경유 및 개인정보·보안 안내

NAIce Shot은 SillyTavern에서 NovelAI 이미지를 생성하는 비공식 확장 프로그램입니다.

본 확장은 브라우저에서 실행되는 일반 확장과 SillyTavern에서 실행되는 서버 플러그인으로 구성되며, **두 구성 요소를 모두 설치해야 이미지 생성 기능을 사용할 수 있습니다.**

서버 플러그인을 요구하는 이유, 외부로 전송되는 데이터, 저장 방식 및 보안상 주의사항을 아래에 안내합니다.

## 1. 어떤 서버를 경유하나요?

NAIce Shot은 개발자가 별도로 운영하는 중계 서버를 이용하지 않습니다.

서버 플러그인은 **사용자 본인이 실행하는 SillyTavern 서버에 설치**됩니다.

- **개인 PC·Termux:** 해당 기기에서 실행 중인 SillyTavern 서버에서 처리합니다.
- **외부 호스팅:** 사용자가 SillyTavern을 설치한 호스팅 서버에서 처리합니다.
- **NovelAI:** 계정 정보 조회와 이미지 생성을 위해 NovelAI 공식 서버(`https://image.novelai.net`)와 통신합니다.
- **장면 추출 AI:** 사용자가 선택한 AI 연결이 외부 서비스인 경우, 해당 AI 제공자의 서버와 통신합니다.

현재 소스에는 개발자에게 데이터를 별도로 전송하는 통계 수집·텔레메트리 기능이 구현되어 있지 않습니다.

다만 외부 호스팅이나 AI 서비스를 이용하는 경우, 해당 서비스의 운영자와 개인정보 처리 정책을 별도로 확인해야 합니다.

## 2. 왜 일반 확장만으로 만들지 않았나요?

SillyTavern에는 이미 NovelAI 계정 정보를 조회하고 이미지를 생성하는 기본 기능이 있습니다.

**단순히 Anlas 잔액을 표시하거나 일반적인 이미지를 생성하는 것만이 목적이었다면 서버 플러그인을 추가할 필요는 없었습니다.**

그러나 NAIce Shot은 기존 이미지 생성 기능을 단순히 호출하는 확장이 아닙니다.

### ① NovelAI 전용 이미지 생성 형식

NAIce Shot은 V5와 V4.5의 모델별 요청 형식을 구분하고, 캐릭터별 독립 프롬프트 슬롯과 위치 정보를 구성하여 NovelAI에 전송합니다.

확인 당시 SillyTavern 기본 이미지 생성 API는 V5 전용 요청 형식과 캐릭터별 독립 슬롯을 동일하게 지원하지 않습니다.

따라서 기존 API를 그대로 호출하는 대신, NAIce Shot의 요구사항에 맞게 이미지 생성 요청을 구성하는 서버 기능이 필요했습니다.

### ② 생성 직전 비용 확인 및 제어

화면에서 Anlas 사용 가능성을 경고하는 것만으로는 실제 생성 요청을 최종적으로 제어할 수 없습니다.

NAIce Shot은 서버에서 NovelAI 구독·사용량 정보를 다시 확인하고, 현재 생성 조건과 사용자의 허용 설정에 따라 요청을 전송하거나 중단합니다.

특히 V5의 남은 사용량이 적거나 불확실한 경우, 정해진 조건에 따라 이번 생성에 대한 별도 확인을 요청합니다.

다만 NovelAI의 사용량이 확인 직후 달라질 수 있으므로, **Anlas가 절대 차감되지 않는다고 보장하지는 않습니다.**

### ③ 중복 생성 방지 및 오류 복구

이미지 생성 요청은 비용이 발생할 수 있으므로, 응답이 끊어졌다는 이유만으로 같은 요청을 다시 보내는 것은 위험합니다.

NAIce Shot 서버는 생성 요청별 ID와 처리 상태를 기록합니다.

이를 통해 이미 보낸 요청을 무작정 재전송하지 않고, 생성 결과의 저장·수신 상태를 확인하거나 복구할 수 있습니다.

이는 단순한 화면 경고와 구분되는 서버 측 기능입니다.

### ④ 이미지 및 작업 기록 관리

생성된 PNG, 프롬프트·생성 설정·장면 기록, 채팅별 마지막 작업을 SillyTavern 사용자 데이터 공간에 저장합니다.

이를 통해 새로고침 후 작업 복원, 이미지 이력 조회, 다른 창이나 기기에서의 수정 충돌 방지 등을 지원합니다.

일반 확장도 기존 저장 API를 활용할 수 있지만, NAIce Shot은 필요한 기록 형식과 저장·복구 규칙을 별도로 구현했습니다.

**즉, 서버 플러그인은 단순한 데이터 중계가 아니라 NAIce Shot의 이미지 생성·비용 관리·기록 보관을 담당하는 핵심 구성 요소입니다.**

## 3. 어떤 데이터가 어디로 전송되나요?

### A. 브라우저 → 사용자의 SillyTavern 서버

기능에 따라 다음 데이터가 전달되거나 서버에 저장될 수 있습니다.

- 최종 이미지 프롬프트 및 캐릭터별 묘사
- 장면·복장 정보와 생성 설정
- 대상 채팅 식별 정보
- 프리샷에 직접 작성한 상황 글
- 생성 요청 ID와 작업·이력 데이터
- 사용자가 보관하도록 설정한 추출 AI 응답 원문(`<think>`, `<thinking>`, `<analysis>`, `<reasoning>` 태그 안의 내용은 빼고 저장합니다. 태그 없이 응답 본문에 쓰인 추론은 남을 수 있습니다.)

서버가 다른 기기나 외부 호스팅에서 실행 중이라면 해당 서버까지 네트워크로 전송됩니다.

### B. SillyTavern 서버 → NovelAI 공식 서버

**계정 정보 확인 시**

SillyTavern에 저장된 NovelAI API 키를 인증에 사용해 계정 정보를 조회합니다.

조회 대상에는 구독 상태, Anlas 잔액, V5 사용량 등 비용 판단에 필요한 항목이 포함됩니다.

**이미지 생성 시**

NovelAI에는 다음 생성 데이터를 전송합니다.

- 최종 긍정·부정 프롬프트
- 캐릭터별 이미지 프롬프트
- 모델, 이미지 크기, 스텝, 시드, 샘플러 등 생성 설정

이미지 생성 요청에 선택한 채팅 원문 전체나 장면 추출 AI 응답 원문 전체를 별도로 첨부하지는 않습니다. 다만 최종 프롬프트에 반영된 대화 내용과 인물 정보는 NovelAI에 전달될 수 있습니다.

NovelAI가 생성한 이미지는 사용자 SillyTavern 서버로 반환되어 저장됩니다.

### C. SillyTavern → 사용자가 선택한 장면 추출 AI

장면 추출 기능을 실행할 경우, 선택한 연결을 통해 다음 내용이 전송될 수 있습니다.

- **챗샷 장면 추출:** 사용자가 선택한 범위의 채팅 메시지(본문, 말한 사람 이름, 캐릭터 메시지라면 그 캐릭터 카드의 파일 이름), 채팅 참여자 이름과 프로필의 연결 정보, 그 메시지에 맞춘 프로필의 이름·별칭·ID·현재 복장, 사용자가 적은 추가 요청
- **프리샷 장면 추출:** 사용자가 적은 상황 글, 저장된 **모든** 프로필의 이름·별칭·ID, 상황에 나온 기존 인물(임시 인물 포함)의 이름(상황 속 인물을 프로필과 맞추는 데 씁니다)

프로필의 '설명으로 만들기' 기능은 입력한 캐릭터 설명과 이름 칸에 입력한 값을 선택한 AI로 전송합니다. 캐릭터 카드나 페르소나에서 프로필을 만들 때는 그 카드·페르소나의 설명이 전송됩니다.

SillyTavern의 연결 방식이나 프리셋에 따라 추가 정보가 포함될 수 있으므로, 사용하는 AI 제공자의 정책도 확인해 주세요.

확장이 임의로 모든 채팅을 NovelAI에 업로드하는 방식은 아닙니다.

## 4. API 키와 개인정보는 안전한가요?

### API 키 처리

NAIce Shot은 브라우저 확장 설정에 NovelAI API 키를 별도로 저장하지 않습니다.

SillyTavern의 서버 측 비밀 키 저장 기능에서 현재 사용자의 NovelAI 키를 읽고, NovelAI 공식 서버 요청의 인증 헤더에 사용합니다.

생성 이력과 설정 백업에는 NovelAI 인증 헤더를 저장하지 않도록 구현되어 있습니다.

이는 브라우저에 API 키를 직접 보관하는 방식을 피하기 위한 설계입니다.

### 이미지와 프롬프트 보관

이미지 생성 기록과 마지막 작업은 사용자의 SillyTavern 데이터 폴더에 보관됩니다.

생성 기록에는 프롬프트·생성 설정·장면 정보가 포함되며, 원본 추출 AI 응답의 추가 보관은 기본적으로 꺼져 있습니다.

원본 PNG에는 이미지 생성 메타데이터가 포함될 수 있습니다. 공유 시 메타데이터를 제거하는 **클린 PNG** 저장 기능을 이용할 수 있습니다.

이미지 파일은 채팅에서 표시할 수 있도록 SillyTavern의 이미지 제공 경로를 사용하므로, 접근 보호는 SillyTavern의 인증·서버 설정에 의존합니다.

## 5. 서버 플러그인 자체의 보안 위험은 없나요?

**위험이 전혀 없다고 보장할 수는 없습니다.**

SillyTavern 서버 플러그인은 일반 브라우저 확장보다 강한 실행 권한을 가집니다.

SillyTavern 공식 문서에서도 서버 플러그인은 격리되어 있지 않으며, 파일 시스템에 접근할 수 있으므로 신뢰할 수 있는 개발자의 플러그인만 설치하도록 안내합니다.

NAIce Shot은 현재 소스에서 다음과 같은 방식으로 불필요한 정보 노출을 줄이도록 설계되어 있습니다.

- NovelAI API 키를 브라우저 확장 설정이나 이미지 기록에 복사하지 않습니다.
- 생성 기록을 이미지 공개 경로와 분리된 사용자 데이터 폴더에 보관합니다.
- 작업·이력 요청에 SillyTavern의 사용자별 경로를 사용합니다.
- 원치 않는 추출 AI 원문 보관을 기본적으로 비활성화합니다.
- 예상치 못한 내부 오류가 화면에 로컬 파일 경로 등을 그대로 표시하지 않도록 처리합니다.
- 개발자에게 별도의 사용 통계나 프롬프트를 전송하는 기능을 두지 않았습니다.

하지만 이러한 설계가 서버 플러그인의 강한 권한을 없애거나 모든 취약점을 방지하는 것은 아닙니다.

소스 코드와 과거 보안 검토 기록을 공개하고 있으며, 보안에 민감한 사용자는 설치 전 직접 확인할 수 있습니다.

**사용 시 권장 사항**

신뢰할 수 있는 환경에서 SillyTavern을 실행하고, 외부에 서버를 공개하는 경우 인증과 HTTPS 등 접근 보호를 확인해 주세요. 자동 업데이트가 우려된다면 `enableServerPluginsAutoUpdate: false`로 설정하고 코드를 검토한 뒤 수동 업데이트할 수 있습니다.

보안 검토와 자동화 테스트는 위험을 줄이기 위한 절차이지, 무결성이나 안전성을 보증하는 인증은 아닙니다.

## 6. 사용 전 확인

NAIce Shot은 일반 브라우저 확장뿐 아니라 서버 플러그인도 설치해야 합니다. 외부 서버 통신이 발생하는 기능은 사용자가 선택한 NovelAI 계정과 AI 연결을 통해 동작합니다.

서버 실행 위치, 외부 제공자에게 전달되는 정보, 저장되는 데이터와 서버 플러그인의 권한을 확인한 뒤 사용해 주세요.

서버 플러그인 설치나 외부 서비스로의 데이터 전송에 동의하지 않는 경우 사용을 권장하지 않습니다.
