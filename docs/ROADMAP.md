# NAIce Shot 남은 계획과 넘겨주기

이 문서는 Claude와 GPT가 번갈아 작업할 때 같은 결정을 보게 하려는 기록이다. 작업 전에 이 문서, [DESIGN.md](DESIGN.md), [REVIEW.md](REVIEW.md)의 규칙을 읽는다. 결정이 바뀌면 이 문서를 먼저 고친다.

## 작업 규칙 (모든 버전 공통)

- **"시작해" 전에는 만들지 않는다.** 설계 논의 중에는 시안·제안만 한다.
- 작업 전 `git pull`. **한 버전은 한 곳에서만 만든다.** 만든 쪽이 아닌 쪽이 리뷰한다.
- 커밋 작성자는 `Near7707 <338649039+Near7707@users.noreply.github.com>`. AI 도구는 공동 작성자 줄로만 적는다.
- 레포(README·예시·테스트·커밋 메시지)에는 **지어낸 이름만** 쓴다(Mira, Leo, Kai, Robin …). 사용자의 실제 캐릭터·이야기 이름·대사·스크린샷은 넣지 않는다.
- 릴리스마다 버전을 올리고(`core.mjs` VERSION, `manifest.json`, `package.json`), CHANGELOG에 **extension only** 또는 **extension + server**를 적는다. 서버가 바뀌면 순서: 서버 업데이트 → 실리태번 재시작 → 확장 업데이트 → 새로고침.
- UI를 고치면 `tests/skins-lint.test.mjs`, `tests/browser-v0149.mjs`를 꼭 돌린다. `npm test`는 서버 레포를 옆에 클론해 둬야 한다.
- 올리기 전 바뀐 부분에서 키·이메일·내 컴퓨터 경로·실제 캐릭터 이름을 점검한다. 비밀 값은 출력하지 않는다.
- REVIEW.md에 버전·커밋·발견 문제(ID, P1~P3)·상태·"이번에 건드린 화면"을 기록한다. 커밋 전에는 "미커밋", 커밋 후 해시로 바꾼다.

### 0.1.59 — 프리샷 인물 처리 개편 · 방향 검토 중 (구현 전)
**검토 목적:** 구현 전에 이 규칙이 (1) 사용자가 만든 카드·편집을 확인 없이 잃게 하지 않는지, (2) 서로 모순되거나 빠진 경우가 없는지, (3) 저장·복원·이력·되돌리기 등 기존 기능과 부딪치지 않는지 확인한다. 배경은 GPT 보고서 UI-054-01~04(카드가 쌓임, ID만 믿음, 임시 인물 외형이 안 바뀜, 분석 중 글 변경).

**원칙:** 그림은 언제나 **입력창 글 기준**. 글에 이름·별칭이 나오는 인물만 그린다. 범위는 **프리샷만**(챗샷은 그대로).

**새 버튼 📌 고정** (프리샷 인물 카드 위쪽 [제거] 옆). 프리샷 작업에만 저장. "남겨 둘 카드"를 사용자가 직접 표시한다. 확장이 몰래 "AI가 넣었는지/직접 넣었는지/고쳤는지"를 추적하지 않는다.

**[장면 추출]을 누를 때, 글에 이름·별칭이 나오지 않는 카드**

| 카드 | 결과 |
| --- | --- |
| 📌 고정 | 카드를 남기고 체크를 푼다(이미 풀려 있으면 그대로). 체크가 풀린 경우 추출 뒤 안내. |
| 고정 안 함 (체크 여부와 상관없이) | **카드를 지운다.** 직접 넣었거나 고쳤어도. 나중에 쓸 카드는 고정해야 한다. |

**글에 나오는 카드:** 이번 결과로 채운다. 고정 카드는 표정·행동은 새로 채우고, 직접 고친 외형(임시 인물)과 옷은 지킨다(옷은 아래 복장 규칙).
**새로 나온 인물:** 프로필 이름·별칭이 유일하게 맞으면 그 프로필 카드, 아니면 새 임시 인물 칸(글에 적힌 외형만). 새 카드는 고정 안 된 상태로 시작.

**추출 전 확인 창:** 지워질 카드가 있거나, **체크된** 고정 카드가 체크 해제될 때만 띄운다.
> 글에 나오지 않는 인물 카드가 있어요. 지워져요: A (고정 안 함) / 체크만 풀려요: B (고정)
> 확인: 그대로 추출 · 취소: 돌아가서 글을 고치거나 고정하기

**"글에 나온다" 판정:** 확장이 직접 한다(AI 응답이 아님). 프로필 이름·별칭, 임시 인물은 카드 이름. 한국어 조사가 붙어도 인정(기존 `mentioned()` 규칙: "레오가", "미라는"). 대명사("그 사람")는 인정하지 않는다 → 확인 창에 나온다. AI에는 글에 나온 카드만 "이미 그림에 있는 사람"으로 보낸다.

**복장:** AI가 넣은 옷은 "자동"으로 기록. 다음 글에서 옷 언급이 없으면 프로필 기본 복장으로 돌아간다. 직접 고친 '이번 그림 복장'과 옷장에서 꺼내 입은 옷은 유지. 프리샷에도 **🔒 복장 잠금**(챗샷과 같은 이름·뜻, 저장은 프리샷 작업에만, 채팅 정보와 섞지 않음): 켜면 글의 새 옷을 적용하지 않고, 직접 고친 옷은 적용. 설명은 "ⓘ 잠금이 뭐예요?"에 접기.

**임시 인물 외형:** 고정 안 한 임시 칸은 새 결과로 통째로 바뀐다(외형·인원 태그 포함). 고정한 임시 칸은 직접 고친 외형을 지킨다.

**검토해 줄 점(미결정·위험):**
1. 체크를 풀어 둔 미고정 카드는 지워지지만, 확인 창 기준(2-1: 체크된 카드만)으로는 **알리지 않고** 지워진다. 이 경우도 확인 창 목록에 넣어야 하는가?
2. 추출 후 되돌리기가 없다(확인 창이 유일한 방어). "↶ 추출 취소" 같은 한 번 되돌리기가 필요한가?
3. 판정이 너무 엄격/느슨한 경우: 짧은 이름이 다른 단어 안에 들어간 경우, 성만 같은 경우, 두 프로필이 같은 별칭을 쓰는 경우, 같은 이름의 임시 인물 둘.
4. 저장·복원: 고정·자동 옷·프리샷 복장 잠금이 마지막 작업과 이력 snapshot에 남는지, 서버의 작업 검증이 새 필드를 지우지 않는지.
5. 다른 기능과의 상호작용: 이력 → 프리샷으로 보내기, 가져오기 취소·비우기 취소, 임시 인물 → 프로필로 저장, 프로필 전환 선택칸, 모드 왕복.
6. 기존 작업(고정 필드가 없는 카드)에 처음 적용할 때 모두 "고정 안 함"이 되어 다음 추출에서 지워질 수 있다. 첫 적용 때 기존 카드를 고정 상태로 둘지.

**완료 기준(검사):** 빈 카드+이름/별칭, A 다음 B만, 고정 A와 "B 혼자", 미고정·체크 해제 카드 삭제, 확인 창 취소 시 아무것도 바뀌지 않음, 잘못된 ID·빈 ID+별칭·모호한 별칭, 임시 외형 갱신과 고정 시 유지, 자동 옷 → 옷 언급 없음 → 기본 복장, 복장 잠금, 저장·복원·이력·되돌리기 뒤 상태 유지, 챗샷 영향 없음.

### 0.1.60 — 메시지 아이콘·그림 표시·이력에서 보기
- 메시지 아이콘: **날짜 줄 오른쪽(나)**, 날짜 줄이 없는 테마는 지금처럼 버튼 줄 끝.
- 메시지에 넣은 그림: 설정에서 **넘겨보기(기본) / 격자 / 세로**, 크기 **작게 / 보통 / 크게**. 비율 유지(세로·가로·정사각형이 섞여도 자르지 않음), 누르면 크게 보기(그 안에서 넘기기).
- 채팅에 넣은 그림을 크게 볼 때 **[이력에서 보기]**: 패널 이력 탭으로 열고 그 카드로 스크롤·강조.

### 0.1.61 — 본문에 넣기 흐름
- 위쪽 "그림을 넣을 메시지" 드롭다운을 없애고, [본문에 넣기]를 누르면 메시지 목록이 최신순으로 열림(만든 메시지 표시·미리 선택).
- 여러 장은 선택 도구 줄 [선택 본문에 넣기] → 같은 목록, "선택된 N장을 넣어요" 안내, 넣은 뒤 배너.

### 3-2 — 메시지 배지·그림 모음 · 설계부터
메시지에 그 메시지에서 만든 그림 수 배지, 메시지별 그림 모음. 서버에 개수 조회가 필요할 수 있어 **UI + 서버**가 될 수 있다. 시안 확정 전 구현하지 않는다.

### 3-3 — 그림마다 넣는 위치
그림별 넣는 위치(메시지 위/아래 등). 우선순위: 그림 설정 > 채팅 설정 > 전체 설정.
