# NAIce Shot 남은 계획과 넘겨주기

이 문서는 Claude와 GPT가 번갈아 작업할 때 같은 결정을 보게 하려는 기록이다. 작업 전에 이 문서, [DESIGN.md](DESIGN.md), [REVIEW.md](REVIEW.md)의 규칙을 읽는다. 결정이 바뀌면 이 문서를 먼저 고친다.

## 작업 규칙 (모든 버전 공통)

- **"시작해" 전에는 만들지 않는다.** 설계 논의 중에는 시안·제안만 한다.
- 작업 전 `git pull`. **한 버전은 한 곳에서만 만든다.** 만든 쪽이 아닌 쪽이 리뷰한다.
- 커밋 작성자는 `Near7707 <338649039+Near7707@users.noreply.github.com>`. AI 도구는 공동 작성자 줄로만 적는다.
- 레포(README·예시·테스트·커밋 메시지)에는 **지어낸 이름만** 쓴다(Mira, Leo, Kai, Robin …). 사용자의 실제 캐릭터·이야기 이름·대사·스크린샷은 넣지 않는다.
- 릴리스마다 버전을 올리고(`core.mjs` VERSION, `manifest.json`, `package.json`), CHANGELOG에 **extension only** 또는 **extension + server**를 적는다. 서버가 바뀌면 순서: 서버 업데이트 → 실리태번 재시작 → 확장 업데이트 → 새로고침.
- UI를 고치면 `tests/skins-lint.test.mjs`, `tests/browser-v0149.mjs`를 꼭 돌린다. `npm test`는 서버 레포를 옆에 클론해 둬야 한다.
- 올리기 전 바뀐 부분에서 키·이메일·내 컴퓨터 경로·실제 캐릭터 이름을 점검한다. 비밀 값은 출력하지 않는다.
- REVIEW.md에 버전·커밋·발견 문제(ID, P1~P3)·상태·"이번에 건드린 화면"을 기록한다. 커밋 전에는 "미커밋", 커밋 후 해시로 바꾼다.

### 0.1.59 — 프리샷 인물 처리 개편 · **완료(GPT 리뷰 대기)**
**검토 목적:** 사용자가 만든 카드·편집을 확인 없이 잃지 않게 하고, 등장 판정·고정·복장 규칙의 모순을 없애고, 저장·이력·취소·모드 전환과 부딪치지 않게 한다. 배경: GPT 보고서 UI-054-01~04, GPT 방향 검토(2026-11-04). 카드 삭제와 [↶ 추출 취소]는 같은 배포에 넣는다.

**원칙:** 등장 인물·장면은 **입력창 글 기준**. 글에 직접 등장하도록 묘사된 인물만 그린다(이름·별칭으로 부르거나 외형으로 묘사). 고정한 외형·직접 선택한 복장은 아래 우선순위를 따른다. **단순화(2026-11-04 확정):** 사용자가 기억할 규칙은 ① 추출하면 체크는 글대로 ② 📌 고정하면 카드(와 임시 인물의 외형·인원 태그)는 안 지워진다 ③ 직접 고른 옷은 남는다, 세 가지다. 범위: **인물 정리·고정·체크·복장 자동/직접 규칙은 프리샷만**(챗샷은 그대로). **프로필 편집기 통합은 챗샷·프리샷 공통 변경**이며, 구현 때 `DESIGN.md`와 관련 검사도 함께 맞춘다.

**📌 고정** (프리샷 인물 카드 위쪽 [제거] 옆, 프리샷 작업에만 저장): 카드를 지우지 않고, 임시 인물이면 **지금 외형과 인원 태그를 함께 유지**한다. 표정·행동은 새 장면으로 채운다. 체크(출연)는 📌과 따로 아래 규칙을 따른다. 카드 전체의 출처(AI/직접)는 추정하지 않는다. 복장은 자동·직접 선택 상태를 카드에 기록한다.

**이름 찾기의 역할:** 확장의 이름 찾기(`mentioned()`, 한국어 조사 허용, 대명사 불인정)는 **카드를 남길지 정하는 데만** 쓴다. 넓게 잡혀도 카드가 남을 뿐이다. 실제로 보이는지는 AI가 정한다.

**포함 체크 = 이번 그림 출연:** 추출이 **성공해 적용될 때마다** 새 장면에 맞춰 다시 정한다(글에 나오고 AI가 보인다고 한 카드만 체크). 추출 뒤 사용자가 바꾼 체크는 생성·재생성에서 그대로 쓰고, 다시 추출할 때만 재계산한다. 실패·중단이면 기존 체크와 작업을 유지한다. "누가 체크를 풀었는지"는 기록하지 않는다.

| 카드 | 결과 |
| --- | --- |
| 글에 이름이 안 나옴 · 📌 고정 | 남기고 체크 해제. 추출 뒤 안내. |
| 글에 이름이 안 나옴 · 고정 안 함 | 체크와 상관없이 **지움**(이번 작업의 카드만, 프로필 원본은 그대로). |
| 글에 이름이 나옴 | AI에 "보이는 경우에만 포함"으로 보냄(지금의 "꼭 넣어라" 지시 변경). 응답에 있으면 체크, 없으면 체크 해제(지우지 않음). |

**새 인물:** 이름·별칭이 하나의 프로필에만 맞으면 그 프로필 카드, 아니면 임시 칸. 임시 칸 이름은 **글에 쓰인 말 그대로**(예: "금발의 상인"). 단, 다음 글에서 "상인"처럼 다르게 부르면 못 찾을 수 있다 → 확인 창·추출 취소로 대응하는 사례로 남긴다. 새 카드는 고정 안 함.

**고정 안 한 임시 인물의 외형 교체:** 글에 계속 나오면 외형·인원 태그가 새 결과로 바뀐다. 매번 확인하지 않는다. 확인 창이 뜰 때는 "다시 채워지는 임시 인물"을 함께 적고, 안 뜰 때는 **추출 뒤 안내 + [↶ 추출 취소]**로 허용한다.

**추출 전 확인 창:** 지워질 카드(체크 여부와 상관없이)나 체크가 풀릴 고정 카드가 있을 때만. 이미 체크가 풀린 고정 카드는 묻지 않는다.
> 글에 나오지 않는 인물 카드가 있어요. 지워져요: A (고정 안 함) / 체크만 풀려요: B (고정) / 다시 채워져요: C (임시)
> 확인: 그대로 추출 · 취소: 돌아가서 글을 고치거나 고정하기
[취소]하면 작업이 하나도 바뀌지 않는다. [확인]을 눌러도 요청이 성공하기 전에는 카드를 지우지 않는다.

**적용 순서:** ① 확인 → ② 응답을 따로 확인(작업은 그대로) → ③ 요청 때와 같은지 확인: 글, 모드, 카드 목록, **포함 체크·고정, 외형·복장 등 카드 편집**, (향후) @참조 ID. 다르면 적용하지 않고 안내 → ④ 안내하지 않은 삭제가 생기면 적용 보류 → ⑤ 한 번에 적용하고 취소 기록 남김.

**[↶ 추출 취소]:** 추출 직전의 프리샷 작업 전체(카드·체크·고정·외형·인원 태그·복장 상태·장면 칸·최종 프롬프트·일회용 설정)를 한 번 되돌린다. 프로필·옷장·설정·생성 이력은 되돌리지 않는다. 가져오기 취소·비우기 취소와 같은 자리에서 **가장 최근에 성공한 작업 하나**만 취소한다. 다음 추출이 **성공적으로 적용되면** 그 추출의 취소로 교체된다. 실패·중단·적용 거부 때는 기존 취소 기록을 유지한다. 비우기·가져오기 성공, 카드나 장면을 직접 고치거나 **생성하면** 사라진다(기존 비우기·가져오기 취소와 같은 규칙).

**복장 (프리샷 잠금은 만들지 않음):** 화면은 지금처럼 복장 칸 하나. 안에서만 "자동(AI 옷 → 없으면 기본 복장)"과 "직접 선택(**빈 값도 그대로 인정**)"을 나눠 기록하고, 직접 선택이 이긴다. "직접 옷 없음"과 "일부러 비움"은 다르다: [비우기]로 비우면 우비나 기본 복장이 되살아나지 않는다(지금은 AI 옷도 `manualOutfit`에 들어가는 구조 → 분리). 다음 글에 옷 언급이 없으면 자동 옷은 프로필 기본 복장으로(기본 복장 없는 임시 인물은 비움).

| 동작 | 결과 (기본=정장, AI=우비, 직접=잠옷 예) |
| --- | --- |
| 칸을 직접 고침·옷장에서 꺼내 입기 | 그 옷을 직접 선택으로 기록 (잠옷) |
| **[기본 복장 입기]** | 프로필 기본 복장을 **직접 선택으로 넣음** (정장). 기본 복장이 없으면 빈 값을 직접 선택 |
| [비우기] | 빈 값을 직접 선택 (옷 태그 없음) |
| **[자동으로 되돌리기]** | 직접 선택을 해제 → AI가 찾은 옷 (우비), 없으면 기본 복장 |

프로필 고정 외형·전용 Positive에 넣어 둔 옷 태그는 건드리지 않는다.

**프로필 편집 하나로 (0.1.57 카드 안 편집 대체):** 인물 카드의 고정 외형 칸 편집과 [프로필 업데이트]·[↶ 업데이트 취소]를 없애고, 카드에는 외형을 보여 주며 **[프로필 편집]이 프로필 탭과 같은 편집기를 카드 자리에 연다**(새 프로필 만들기 자리 재사용). 저장 경로·확인 창은 하나. 편집기에 작성 중인 내용이 있으면 다른 프로필을 열 때 지우지 않고 묻는다. 0.1.58의 저장 충돌 방지(폼이 안 고친 칸은 그 사이 저장값 유지)는 그대로.

**취소 정리:** 그리기 작업의 비우기·가져오기·추출 취소는 같은 "직전 작업 취소" 한 칸. 채팅 기본 복장 해제 취소는 채팅 정보라 따로. 프로필 업데이트 취소는 위 변경으로 사라진다. 채팅별 작업 분리·늦은 응답 차단·저장 충돌 검사·삭제된 작업이 살아나지 않게 하는 장치는 유지.

**저장:** 고정·복장 상태(자동/직접)는 카드 안에 둔다(`packWork`가 카드·장면 안 칸은 보존함을 확인). UI와 서버 양쪽에서 저장→불러오기 검사를 한 뒤 서버 변경 여부를 확정한다.

**예전 작업·이력:** 고정 표시가 없는 카드는 불러올 때 **고정으로 바꾸고 그 값을 저장**한다(오래된 이력을 가져올 때도 같음). 명시적으로 '고정 안 함'인 카드는 그대로. 출처를 모르는 옷(예전 임시 인물의 복장 포함)은 **직접 선택한 옷으로 간주해 유지**한다. 고정 변환과 복장 출처 변환은 따로, 불러올 때마다 실행한다(0.1.61). AI가 채운 옷은 자동으로 기록한다.

**다른 기능:** 임시 인물 → 프로필 저장(`convertTemp`) 때 고정·체크·복장 상태(빈 직접 선택 포함)를 넘긴다. **프로필 선택칸 전환** 때는 고정·체크는 유지하고, 복장은 카드 안내("변경하면 새 프로필의 복장을 사용해요")대로 새 프로필 기준으로 초기화한다(직접·자동 모두, 0.1.60 확정). 카드 병합은 지금 경로가 없다. **양쪽에 값이 있으면:** 같은 값은 그대로 합치고, 서로 다른 직접 입력(외형·직접 복장 등)이 부딪칠 때만 어느 쪽을 살릴지 묻는다. 고정은 하나라도 고정이면 고정. 이력 → 프리샷은 저장된 작업 상태를 복원하고 채팅 복장·잠금은 읽지 않는다. 챗샷↔프리샷 왕복은 서로 영향 없음.

**완료 기준(검사):** 빈 카드+이름/별칭, A 다음 B만, 고정 A와 "B 혼자", 인물 없는 배경, 미고정·체크 해제 카드 삭제 확인, 확인 창 취소 시 변화 없음, 임시 외형 교체 안내와 고정 시 유지, 짧은/긴 이름·조사·일반 단어 이름·"X는 없다", 공유 별칭·같은 이름 임시 칸 둘, 잘못된 ID·빈 ID+별칭, 자동 옷 → 옷 언급 없음 → 기본 복장, 직접·옷장 옷, [기본 복장 입기]=기본 옷 직접 선택·[자동으로 되돌리기]=AI 옷, 추출 성공 때만 체크 재계산·사용자 체크는 생성에서 유지, 카드 [프로필 편집]=같은 편집기·작성 중 내용 보호, 추출 중 글·체크·고정·카드 편집·모드 변경, 실패·중단 시 취소 기록 유지, 추출 취소·비우기 취소·가져오기 취소, 예전 작업·옛 이력, 카드 변환·프로필 전환, 서버 저장 왕복, 챗샷 영향 없음. AI 응답은 고정 응답으로만 검사한다(실제 모델의 지시 준수율은 검증했다고 적지 않음).
