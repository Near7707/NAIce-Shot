# NAIce Shot 남은 계획과 넘겨주기

이 문서는 Claude와 GPT가 번갈아 작업할 때 같은 결정을 보게 하려는 기록이다. 작업 전에 이 문서, [DESIGN.md](DESIGN.md), [REVIEW.md](REVIEW.md)의 규칙을 읽는다. 결정이 바뀌면 이 문서를 먼저 고친다.

## 작업 규칙 (모든 버전 공통)

- **"시작해" 전에는 만들지 않는다.** 설계 논의 중에는 시안·제안만 한다.
- 작업 전 `git pull`. **한 버전은 한 곳에서만 만든다.** 만든 쪽이 아닌 쪽이 리뷰한다.
- 커밋 작성자는 `Near7707 <338649039+Near7707@users.noreply.github.com>`. AI 도구는 공동 작성자 줄로만 적는다.
- 레포(README·예시·테스트·커밋 메시지)에는 **지어낸 이름만** 쓴다(Mira, Leo, Kai, Robin …). 사용자의 실제 캐릭터·이야기 이름·대사·스크린샷은 넣지 않는다.
- 릴리스마다 버전을 올리고(`core.mjs` VERSION, `manifest.json`, `package.json`), CHANGELOG에 **extension only** 또는 **extension + server**를 적는다. 서버가 바뀌면 순서: 서버 업데이트 → 실리태번 재시작 → 확장 업데이트 → 새로고침.
- UI를 고치면 `tests/skins-lint.test.mjs`, `tests/browser-v0149.mjs`를 꼭 돌린다. `npm test`는 서버 레포를 옆에 클론해 둬야 한다.
- 올리기 전 바뀐 부분에서 키·이메일·내 컴퓨터 경로·실제 캐릭터 이름을 점검한다. 비밀 값은 출력하지 않는다.
- REVIEW.md에 버전·커밋·발견 문제(ID, P1~P3)·상태·"이번에 건드린 화면"을 기록한다. 커밋 전에는 "미커밋", 커밋 후 해시로 바꾼다.

### 0.1.57 — 다듬기 · 끝남 (확장만, 4da3b6e, 서버 README만 보완)
**① 설정 → 공통 이미지 프리셋**
- [불러오기]는 맨 위. 짧은 칸은 폰에서도 두 칸씩: 모델·이미지 크기 / 스텝·Guidance / Seed·CFG Rescale.
- 저장 이름과 버튼은 **NAI 생성 설정 맨 아래 상자**("프리셋으로 저장")로 옮긴다.
- 버튼은 **현재 선택 기준**: 프리셋을 고른 상태 → 주 버튼 **[변경 저장 · 이름]**(확인 창) + [새 프리셋으로 저장] + [선택 프리셋 삭제]. [+ 새 프리셋 만들기] → 모든 칸 비우고 선택 해제, [새 프리셋으로 저장]만. 이름은 한 줄 "…".
- DESIGN.md의 "덮어쓰기는 주 버튼이 아니다"를 "선택된 프리셋의 변경 저장은 확인 창과 함께 주 버튼"으로 고친다.

**② 그리기 → 인물 카드 옷**
- [지금 옷을 기본으로]·[옷장에 저장]을 "이번 그림" 묶음 안 **"이 복장을"** 줄로: [이 채팅 기본으로] / [옷장에 저장]. "이 채팅에서"는 채팅 기본 복장 선택·안내·잠금만.
- 입력칸 이름 **"이번 그림 복장"**.
- 잠금 설명은 평소 접기("ⓘ 잠금이 뭐예요?", 열 수 있다는 게 보이게). 문구: "켜면 AI가 메시지에서 새 옷을 찾아도 그림에 적용하지 않아요. 채팅 기본 복장을 계속 입고, 채팅 기본 복장이 없으면 프로필 기본 복장을 입어요. '이번 그림 복장'에서 직접 고친 옷은 그대로 적용돼요."

**③ 그리기 → 고정 외형 · 전용 태그**
- 펼치면 고정 외형·전용 Positive·전용 Negative를 고친다. 작은 **[프로필 업데이트]** 하나(새 프로필로 저장은 만들지 않음).
- 확인 창: "\"이름\" 프로필의 고정 외형과 전용 태그를 지금 내용으로 바꿔요. 이 프로필은 모든 채팅에서 함께 쓰여서, 다른 채팅에서 만드는 그림에도 바뀐 외형이 적용돼요. 계속할까요?" 업데이트 직후 한 번 [↶ 업데이트 취소].

**④ 설정 이름·문구 「추출 AI 응답 원문 추가 보관」**
- 짧은 설명: "이 옵션을 꺼도 생성 기록(JSON)은 실리태번 폴더에 저장돼요. 프롬프트·생성 설정·seed·장면·생성 일시·채팅 정보가 포함되며, 프리샷은 직접 쓴 상황 글도 저장돼요."
- "이 옵션은 추출 AI의 응답 원문을 이력과 마지막 작업에 추가로 보관할지만 정해요. **개인정보 주의: 응답에 이름·대화 인용 등이 포함될 수 있어요.** 옵션을 꺼도 기존 생성 이력에 보관된 응답 원문은 삭제되지 않아요."
- 자세한 설명: 채팅 메시지 원문을 따로 복사해 보관하지는 않지만, AI가 인용한 내용은 결과에 남을 수 있다. 이력 탭 저장 위치 안내와 서버 README도 같은 내용으로.

**⑤ PC 정렬**: 내용 전체를 640px 가운데 열로(입력칸·버튼 끝 맞춤).

**⑥ 작은 수정**: 이력 [모두 선택] ↔ [모두 해제](하나라도 선택되면 해제), 채팅 메시지 ⋯ 메뉴에 테마 색, 이력 탭의 긴 설명 접기(경고 문구는 펴 둠), "↻ 새로고침" 글자.

**⑦ 이력 탭 저장 위치 안내(확인된 사실만)**: 그림 `data/<사용자>/user/images/naice-shot/<ID>.png`, 기록 `data/<사용자>/naice-shot-records/`, 작업 `data/<사용자>/naice-shot-work/`. 이력에서 지우면 그림·기록 함께 삭제. 기록 없이 남은 그림은 확장에 안 보이고 폴더에서 직접 지움. 실리태번에서 채팅을 지워도 그림·기록은 남음(전체 보기에서 삭제). 브라우저 다운로드는 사본.

### 0.1.58 — 메시지 아이콘·그림 표시·이력에서 보기
- 메시지 아이콘: **날짜 줄 오른쪽(나)**, 날짜 줄이 없는 테마는 지금처럼 버튼 줄 끝.

### 3-2 — 메시지 배지·그림 모음 · 설계부터
메시지에 그 메시지에서 만든 그림 수 배지, 메시지별 그림 모음. 서버에 개수 조회가 필요할 수 있어 **UI + 서버**가 될 수 있다. 시안 확정 전 구현하지 않는다.
