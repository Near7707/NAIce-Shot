장면 추출 중
챗샷은 열린 채팅의 장면을, 프리샷은 채팅과 상관없이 적은 상황을 그려요. 장면·프롬프트는 서버에 따로 기억해요.

1 · 그릴 순간

대상 메시지의 장면을 그려요. 앞선 메시지는 참고용이에요. 한 메시지에 장면이 여러 개면 최대 3개의 후보를 보여주고, 기본으로는 마지막 순간을 골라요. 캐릭터·유저 외의 등장인물도 함께 찾아요.

대상 메시지
가장 최근 메시지
숨긴 대화도 고를 수 있어요. 숨긴 메시지를 직접 고르면 그 메시지와 앞선 참고 범위의 대화(숨김 포함)를 추출 AI에 보내요. 본편의 하이드는 유지돼요.
이 채팅의 프로필 연결 · 자동 인식 확인

현재 카드·유저 이름과 프로필 이름·별칭으로 자동 연결해요. 이름이 다르면 이 채팅에서 사용할 프로필을 한 번 지정할 수 있어요.

보낼 메시지 수가 1이면 대상 메시지만 보내요. 인물·복장·상황이 앞 메시지에서 이어지면 늘려 주세요. 앞 메시지는 지금 상태를 이해하는 자료로만 쓰고, 후보는 대상 메시지에서만 골라요.

상황을 적고 [장면 추출]을 누르면 AI가 아래 장면 칸을 채워 줘요. 프로필에 등록한 이름이나 별칭을 쓰면 인물을 미리 추가하지 않아도 그 프로필로 넣어 줘요. 프로필이 없는 인물은 글에 적힌 외형으로 임시 인물이 돼요. 칸을 직접 채워도 돼요.

프로필 인물은 저장된 외형을 그대로 써요. 여러 동작을 적으면 한 순간으로 골라요.
그리고 싶은 순간이나 바꿀 내용을 적어 주세요. 입력 후 '장면 추출'을 누르면 반영돼요. 이번 추출·그림에만 적용되고, 원문·프로필·채팅 기본 복장은 바뀌지 않아요. 대상 메시지를 바꾸면 비워져요.
추출 응답 확인

2 · 장면 편집

아직 등록된 캐릭터 프로필이 없어요.

외형을 대충 적으면 AI가 이미지용 태그로 바꿔 줘요. 여기서 바로 만들고 장면에 넣을 수 있어요.

새 프로필
최종 프롬프트 · 이번 생성용 직접 수정 직접 고침

NAI로 보낼 내용을 이번 생성에 한해 칸별로 고칠 수 있어요. 생성에 성공하면 조립 결과와 현재 생성 설정으로 돌아가요. 실패하면 재시도할 수 있도록 유지하고, 채팅별 마지막 작업에 함께 기억해요.

채팅 속 그림 위치

이 채팅에서만 다르게 정할 수 있어요. 이미 넣은 그림도 바로 자리가 바뀌어요. 보이는 자리만 달라지고 메시지 글·AI 입력·기억 요약에는 영향이 없어요.각 메시지의 추가 메뉴(…)에 그리기 버튼을 넣어요. 누르면 그리기 탭이 열리고 그 메시지가 대상으로 골라져요. 장면 추출과 생성은 직접 눌러 진행해요. 꺼 두면 버튼을 붙이는 작업도 하지 않아요.

추출 AI

별도 연결 프로필을 선택하면 본편 연결을 바꾸지 않고 그 연결로 추출해요. 추출 요청에도 해당 AI의 사용량·API 비용이 들어가요.

권장: 별도 연결 프로필로 추출하고 응답 한도는 8192부터 시작하세요. 본편 연결로 추출하면 본편 프리셋의 응답 길이가 그대로 적용돼서, RP용으로 짧게 잡혀 있으면 장면 후보가 잘릴 수 있어요. 한도는 최대치라 늘려도 실제로 쓰는 양은 응답 길이만큼이에요.

별도 연결 프로필을 사용할 때만 적용돼요. 생각(reasoning)이 긴 모델은 응답이 잘리면 더 늘려 주세요.별도 연결 프로필로 추출할 때만 이번 요청에 실어 보내요. 본편 설정은 바뀌지 않아요. 낮을수록 매번 비슷한 장면 후보가 나와요. 온도를 지원하는 모델에서만 효과가 있고, 생각 모드처럼 무시하는 모델도 있어요.지원하지 않는 연결에서는 끄고 일반 JSON 추출을 사용할 수 있어요. 프로필은 실리태번의 API 연결 → 연결 프로필에서 먼저 저장해 주세요.

고급

추출 AI 응답 원문 추가 보관이 옵션을 꺼도 생성 기록(JSON)은 실리태번 폴더에 저장돼요. 프롬프트·생성 설정·seed·장면·생성 일시·채팅 정보가 포함되며, 프리샷은 직접 쓴 상황 글도 저장돼요.이 옵션은 추출 AI의 응답 원문을 이력과 마지막 작업에 추가로 보관할지만 정해요. 옵션을 꺼도 기존 생성 이력에 보관된 응답 원문은 삭제되지 않아요.

개인정보 주의 응답에 이름·대화 인용 등이 포함될 수 있어요.

자세히채팅 메시지 원문을 따로 복사해 보관하지는 않아요(어느 메시지인지 알아보는 짧은 지문과 작성 시각만 남아요). 하지만 AI가 인용한 내용은 장면 결과와 응답 원문에 남을 수 있어요. 응답 원문은 PNG에는 들어가지 않고, 생각 과정(reasoning)은 빼고 보관해요. 저장 위치는 이력 탭의 "저장 위치" 안내를 봐 주세요.

마지막 작업 기억

모든 채팅과 프리샷의 작성 중인 작업을 삭제해요. 삭제 후에는 이어서 작업하거나 되돌릴 수 없어요. 생성한 그림·이력·프로필·설정은 유지돼요.

설정 백업

개인정보 주의 백업에는 프로필·별칭·옷장·프롬프트가 포함돼요. 다른 사람에게 공유하기 전에 확인해 주세요.

채팅별 "채팅 기본 복장"은 그 채팅 파일에, 이미지 이력과 마지막 작업은 서버에 따로 저장돼요. 백업에는 캐릭터 프로필·별칭·옷장·공통 프롬프트·프리셋이 포함돼요. 공유 전에 확인해 주세요. API 키는 들어가지 않아요.

PNG 저장 안내

클린 PNG는 프롬프트·seed 등 메타데이터(EXIF 포함)를 모두 지운 사본이에요. 투명한 부분은 불투명하게 바뀌어요.

원본 PNG는 메타데이터를 그대로 저장해서, 다른 곳에 올리면 프롬프트가 보일 수 있어요.

공유하기 전에 다시 한번 확인하세요.

  • 이력에서 지우면 그림 파일과 기록이 함께 지워져요.
  • 기록 없이 그림 파일만 남는 경우(기록을 쓰다 실패했거나 손으로 지운 경우)는 이력에 보이지 않아서, 폴더에서 직접 지워야 해요.
  • 실리태번에서 채팅을 지워도 그 채팅의 그림과 기록은 남아요. "전체 보기"에서 지울 수 있어요.
  • 클린·원본 PNG와 ZIP은 기기의 다운로드 폴더로 받는 사본이에요. 이력과는 상관없어요.
