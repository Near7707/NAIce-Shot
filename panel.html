장면 추출 중

1 · 그릴 순간

대상 메시지의 마지막 장면을 그려요. 앞선 메시지는 참고용이에요.

이 채팅의 프로필 연결 · 자동 인식 확인

현재 카드·유저 이름과 프로필 이름·별칭으로 자동 연결해요. 이름이 다르면 이 채팅에서 사용할 프로필을 한 번 지정할 수 있어요.

추출 응답 확인

2 · 장면 편집

아직 등록된 캐릭터 프로필이 없어요.

외형을 대충 적으면 AI가 이미지용 태그로 바꿔 줘요. 여기서 바로 만들고 장면에 넣을 수 있어요.

새 프로필
최종 프롬프트 · 이번 생성용 직접 수정 직접 고침

NAI로 보낼 내용을 이번 생성에 한해 칸별로 고칠 수 있어요. 장면·프로필·공통 설정을 바꾸면 고친 내용은 조립 결과로 돌아가요.

JSON으로 직접 수정 · 고급

3 · 생성

저장한 포지·네거와 생성 설정을 바로 불러와요. 프리셋 저장·수정은 설정 탭에서 할 수 있어요.

V5는 기본 무료 조건 안에서도 무료 잔량에 따라 비용이 들 수 있어요. 잔량은 NAI에서 확인해 주세요.

캐릭터 프로필

고정 외형은 AI에 전달하지 않고, 이미지 요청에만 넣어요. 복장은 별도 칸에 입력해 주세요.

새 프로필 작성 중
추출 AI 연결로 아래 외형·기본 복장·Negative 칸을 채워요. 결과를 확인하고 고친 뒤 저장해 주세요.

채팅 속 그림 위치

이미 넣은 그림도 바로 자리가 바뀌어요. 보이는 자리만 달라지고 메시지 글·AI 입력·기억 요약에는 영향이 없어요.

공통 이미지 프리셋

긍정·부정 프롬프트와 아래 NAI 생성 설정 전체를 한 묶음으로 저장해요. 모델·크기·스텝·가이던스·시드·CFG 재조정·샘플러가 포함돼요.

공통 프롬프트

NAI 생성 설정

서버 플러그인 설치와 실리태번 NAI 키 저장이 필요해요.

추출 AI

별도 연결 프로필을 선택하면 본편 연결을 바꾸지 않고 그 연결로 추출해요. 추출 요청에도 해당 AI의 사용량·API 비용이 들어가요.

별도 연결 프로필을 사용할 때만 적용돼요. reasoning이 긴 모델은 한도를 늘릴 수 있어요.지원하지 않는 연결에서는 끄고 일반 JSON 추출을 사용할 수 있어요. 프로필은 실리태번의 API 연결 → 연결 프로필에서 먼저 저장해 주세요.

개인정보 보관

기본은 꺼짐이에요. 켜면 사고 태그를 제거한 추출 응답을 이력에 저장해요. 지금 추출 결과는 저장 여부와 관계없이 확인할 수 있어요. 이미 저장된 이력은 바뀌지 않아요.

PNG 저장은 원본을 유지해요. 공유용 PNG는 프롬프트 메타데이터와 알파 채널 정보를 제거한 불투명 사본을 만들어요. 원본과 이력은 그대로예요.

설정 백업

현재 채팅 복장과 이미지 이력은 서버에 별도로 저장돼요. 백업에는 캐릭터 프로필·별칭·공통 프롬프트·프리셋이 포함돼요. 공유 전에 확인해 주세요. API 키는 들어가지 않아요.

스킨

패널의 색과 모양을 바꿔요. 기본을 뺀 스킨은 실리태번 테마와 상관없이 같은 색으로 보여요.

생성 이력

편집으로 불러오면 당시 최종 프롬프트와 생성 설정을 이번 생성에 써요. 현재 복장과 설정 탭 값은 바뀌지 않아요.

삭제하면 서버의 원본 PNG와 생성 기록이 지워져요. 지금 채팅에 붙인 그림은 함께 빠지고, 다른 채팅에 붙여 둔 그림은 그 채팅에서 "찾을 수 없는 그림" 안내로 바뀌어요. 되돌릴 수 없어요.
